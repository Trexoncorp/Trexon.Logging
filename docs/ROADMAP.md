## MVP 0.1.0-alpha.1

- Fluent API: `MinimumLevel`, `Enrich`, `Redact`, `Filter`, `OnError`, `WriteTo`.
- `Logger`, процессный фасад `Log`, структурированный `LogEvent`.
- Уровни, шаблоны сообщений, типизированные свойства и снимки исключений.
- Консоль: дата, цвета, caller info. Файл: append, UTF-8, JSON Lines.
- `Bind`, вложенные async-flow-local scopes, изоляция контекста.
- Маскирование строковых данных, timeout регулярок, обработка ошибок sinks.
- Синхронная запись, `Flush`, владение ресурсами и безопасное закрытие.
- Поведенческие тесты на .NET 8/.NET 10 и запускаемый консольный пример.
- NuGet-пакет и workflow с тестами перед публикацией.
- Документация на русском, английском и немецком с переключением языка и проверкой примеров.

Первый prerelease — `0.1.0-alpha.1`. До версии 1.0 API может меняться;
совместимость будущих версий нужно проверять при обновлении.

## Следующие этапы

| Этап | Состав | Критерий готовности |
| --- | --- | --- |
| 1. Файлы | Ротация по размеру/времени, retention, затем compression | Проверены границы ротации, конкурентная запись, ошибки диска и политика хранения |
| 2. Очередь | Ограниченный Channel, политика переполнения, FlushAsync/DisposeAsync | Проверены порядок, ожидаемые потери/блокировки и завершение с непустой очередью |
| 3. Интеграция | Пакет Trexon.Logging.Extensions.Logging, ILoggerProvider, scopes, DI/Host | Логи приложения и ASP.NET Core проходят через один pipeline без циклов и дублей |
| 4. Укрепление | Benchmarks, расширение шаблонов, удобные JSON-настройки, стратегия caller info | Проверены реальные сценарии потребления и стоимость включённых возможностей |
| 5. API 1.0 | Совместимость, документация, стабильные контракты | Подтверждены поведение и совместимость на Linux, Windows, macOS |

Настройки через C#-атрибуты при необходимости можно добавить как альтернативный
способ собрать ту же конфигурацию. Основной API остаётся fluent.

# Документация Trexon.Logging

[Русский](README.md) · [English](en/README.md) · [Deutsch](de/README.md)

[Главная страница проекта](../README.ru.md)

Эти материалы описывают стабильную версию `1.0.0`. Начните с готового
примера, затем переходите к нужной возможности. Полные блоки C# с отметкой
`verify` проверяются командой `python3 scripts/check-docs.py`; блоки сигнатур
в справочнике показывают контракт API и не являются отдельными программами.

## Маршрут изучения

1. [Быстрый старт](GETTING_STARTED.md): требования, установка, первое приложение.
2. [Fluent-конфигурация](CONFIGURATION.md): уровни, фильтры, снимки настроек, часы.
3. [Сообщения и свойства](MESSAGES.md): placeholders, форматы, сложные значения.
4. [Контекст](CONTEXT.md): глобальные свойства, `Bind`, async-области `PushScope`.
5. [Получатели и форматы](OUTPUT.md): консоль, цвета, файлы, схема JSON.
6. [Маскирование](REDACTION.md): регулярки, порядок правил, timeout и границы.
7. [Ошибки и время жизни](ERRORS_AND_LIFETIME.md): исключения, сбои sinks,
   `Flush`, `Dispose`, процессный фасад.
8. [Расширение](EXTENDING.md): собственный `ILogSink` и его ресурсы.

## Что уже доступно

| Область | Возможности |
| --- | --- |
| Запись | `Logger`, статический `Log`, шесть уровней и `None` |
| Данные | Шаблон, сообщение, типизированные свойства, снимок исключения, caller |
| Настройка | Fluent API, глобальный и локальные уровни/фильтры, `TimeProvider` |
| Контекст | `WithProperty`, `Bind`, вложенные `PushScope` на `AsyncLocal` |
| Вывод | Консоль, пользовательский `TextWriter`, файл, текст и JSON Lines |
| Оформление | Время и зона, ANSI-цвет по уровню, caller, подробности исключения |
| Обработка | Маскирование строк по регуляркам, ограниченное время regex-операции |
| Расширение | Структурированный `ILogSink`, управление владением, `OnError` |
| Завершение | Синхронные `Flush` и `Dispose`, отдельное время жизни bound views |
| Доставка | `.nupkg`, `.snupkg`, XML-документация, CI и workflow по тегам |

Многопроцессная запись в общий файл, очередь, ротация и интеграция с DI/Host
как готовый пакет относятся к [следующим этапам](ROADMAP.md).
